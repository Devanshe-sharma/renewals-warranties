Before this change each mail had its own subject ("New Ticket Raised - ...", "Ticket ... - Status: ...", "Follow-up Requested - ..."), so most mail clients (Gmail, Outlook) started a separate thread for each. Now every mail for a given ticket uses "Ticket <ticket_id>: <title>", so they land in one conversation.
